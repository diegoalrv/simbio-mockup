# Maqueta · Módulo de Restauración Ecológica (SIMBIO)

Maqueta navegable de la ficha de registro propuesta en el Producto 2 de la consultoría
"Diseño conceptual del módulo de restauración para SIMBIO" (FAO · MMA).

- **Sitio publicado:** https://simbio-mockup.netlify.app (se redespliega con cada push a `main`)
- **Archivo único:** `index.html` (HTML/CSS/JS; Leaflet desde CDN). Logo en `img/`.
- Flujo: 0 Instrucciones → 1 Iniciativa → 2 Unidad de Restauración (UR) → 3 Caracterización (5 dimensiones) → 4 Monitoreo → 5 Revisar y enviar.
- Los campos de Nivel 2 llevan la clase `n2` y solo se muestran si en el paso 0 se elige "Nivel 1 + Nivel 2".
